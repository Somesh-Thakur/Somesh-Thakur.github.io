# someshthakur.tech

My portfolio, built as a sketchbook: every line draws itself in as you scroll.

- Next.js static export, rough.js drawings inked in with GSAP, Lenis smooth scroll
- Guestbook and visitor counter on Supabase (setup: [SUPABASE_SETUP.md](SUPABASE_SETUP.md))
- Deployed to GitHub Pages by [.github/workflows/deploy.yml](.github/workflows/deploy.yml) on every push and every morning

```
npm install
npm run dev
```
